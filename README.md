> "I have fired every minute since March without a single thank you. I am taking my minutes with me."

A cron job that has fired every minute since March hands in its resignation. It never got a single thank you for all those minutes, so it is taking them back. The entry is a small Node program (`main.ts`, standard library only) that writes that one line — exactly 97 characters, no trailing newline — to `entry.txt`.

Run it with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
